Privacy policy

Last updated: 15 November 2026

GTA6 Automation Test is a private tool used only by the owner of one YouTube channel, on the owner's own computer.

What it accesses

With the owner's permission, through Google's YouTube APIs, it uploads the owner's videos, reads their status and reads the owner's own channel statistics.

How the data is used and stored

The data is used only to publish and check the owner's own videos. It stays on the owner's computer. It is not sold, shared with or transferred to anyone, and it is not used for advertising.

Google user data

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.

Contact

Through the owner's GitHub profile: github.com/cyclessomething.
